# Mes courses

Petite app web minimaliste pour préparer ses listes de courses.

## Fonctionnalités
- Rayons (Fruits & légumes, Frais, Épicerie, Boissons, Maison, Autre) avec cases à cocher
- Ajout d'aliments dans chaque rayon
- Recettes : un clic ajoute tous les ingrédients à la liste
- Fin de courses : les achats alimentent vos habitudes
- Données enregistrées localement sur l'appareil (localStorage)

## Utilisation
https://uuzer123.github.io/Mes-courses/
Sur téléphone : ouvrir le lien, puis « Ajouter à l'écran d'accueil ».

## Installer sur téléphone (PWA)
Une fois publiée sur GitHub Pages (HTTPS), l'app est installable :
- **iPhone (Safari)** : Partager → Sur l'écran d'accueil
- **Android (Chrome)** : menu ⋮ → Installer l'application

Elle fonctionne ensuite hors connexion, avec sa propre icône.
